# スクリーンショット撮影ツール

`src/_locales/` にある言語ぶんだけ、ストア掲載用の `screen1` / `screen2` を
1280x800 で撮影し `screenshots/<言語>/` に出力する。

拡張機能本体には含まれない（配布zipは `src/` から作るため）。Windows専用。

## 準備（初回のみ）

```
cd tools/screenshots
npm install
npx @puppeteer/browsers install chrome@stable
```

通常のChromeは使えない。**Chrome 137 以降 `--load-extension` が削除された**ため、
コマンドラインから拡張機能を読み込めるのは Chrome for Testing だけ。
別の場所にあるものを使う場合は `CHROME_PATH` で指定する。

## 使い方

```
node take-screenshots.js            # 全言語
node take-screenshots.js ja         # 日本語のみ
node take-screenshots.js fr:fr-FR   # _locales/fr を Chrome の fr-FR で撮る
```

言語フォルダ名がそのまま Chrome の `--lang` になる（`pt_BR` のような
アンダースコアは `pt-BR` に変換される。Chrome はこの形式でないと認識しない）。
異なる値を渡したいときだけ `フォルダ名:Chromeの言語` の形式で指定する。

**撮影中はChromeウィンドウが画面を占有する。** OSの画面キャプチャを使うため、
他の作業と並行してはいけない。

## 前提と、そうしている理由

つまずいた点をそのまま残してある。値を変えるときの判断材料に。

### 撮影方法

- **OSの画面キャプチャを使う。** タブ・アドレスバー・ポップアップはブラウザのUIであり、
  Chromeのスクリーンショット機能では撮れない。
- **DPI認識が必須。** これを有効にしないと、200%スケーリング環境では画面が 960x600 として
  見えてしまい 1280x800 を切り出せない。物理解像度が足りないと誤解しやすい。
- **不可視のリサイズ枠を除く。** `GetWindowRect` の値で切り出すと背後のデスクトップが
  写り込む。`DWMWA_EXTENDED_FRAME_BOUNDS` を使う。

### 表示倍率（`SCALE_POPUP` / `SCALE_OPTIONS`）

- **ポップアップはページの拡大では大きくならない。** ブラウザUIなので、表示倍率
  (`--force-device-scale-factor`) でしか調整できない。`screen1` は 1.75。
- **オプション画面は 1.45。** 1.75のままだと高さ200pxのホワイトリスト入力欄が画面外に出る。
  2.0まで上げると横にはみ出して横スクロールバーが写り込む。
  スクリプトが撮影前に実測し、はみ出しや見切れがあれば警告を出す。

### ポップアップを開く（`screen1`）

- **アイコンをツールバーにピン留めする。** しないと表示位置が定まらない。
  プロファイルの `Preferences` に直接書き込んでいる。
- **`chrome.windows.update({focused:true})` が必須。** `openPopup()` は Chrome が
  アクティブと見なすウィンドウしか受け付けず、OSレベルの `SetForegroundWindow` では
  条件を満たせない。
- **順序を守る。** 上記の呼び出しは Chrome が保持するウィンドウサイズを復元してしまうので、
  そのあとに物理サイズを与え直す。ポップアップを開いたあとに動かすと閉じてしまうため、
  サイズ確定は必ず開く前に行う。

### 背景ページ（`BACKDROP`）

- **シンプルなページにする。** 情報量が多いと拡張機能のUIが埋もれる。
- **Google検索は使わない。** 自動操作とみなされて reCAPTCHA 画面になり、
  そこにグローバルIPアドレスが表示される。
- **ホワイトリストの記入例と別のドメインにする。** 同じにすると、ポップアップが
  「ホワイトリストから除外する」状態（灰色）になってしまう。
  未登録のドメインにして「ホワイトリストに追加する」を見せる。

### capture.ps1 の文字コード

**UTF-8 BOM付きで保存すること。** Windows PowerShell 5.1 は BOM が無いと ANSI として
読み込むため、日本語コメントが壊れて構文エラーになる。

## UIの文言を変えたときは

全言語を撮り直す。文言は `src/_locales/<言語>/messages.json` が正。
