# スクリーンショット

Chrome ウェブストアの掲載画像は拡張機能のパッケージには含まれず、
デベロッパーダッシュボードから**言語ごとに**アップロードする。
言語別に用意しない場合は既定言語(本拡張機能では英語)の画像が使われる。

```
screenshots/
  en/   英語ロケール向け（既定言語）
  ja/   日本語ロケール向け
  …     src/_locales/ の言語フォルダと同じ名前で並べる
```

現在の対応言語は `src/_locales/` を正とする。画像を用意していない言語は
既定言語(英語)の画像が使われるため、未整備でも掲載自体は成立する。

## 要件

- 1280x800(推奨) または 640x400 の PNG / JPEG
- 角丸・余白なし(フルブリード)
- 1枚以上、最大5枚

## 撮り直しの手順（自動）

`tools/screenshots/` のスクリプトで全言語ぶんを撮影できる。

```
cd tools/screenshots
node take-screenshots.js        # 全言語
node take-screenshots.js ja     # 言語を指定
```

初回の準備、倍率や背景ページの選定理由は `tools/screenshots/README.md` を参照。
以下は手作業で撮る場合の手順。

## 撮り直しの手順（手動）

ブラウザのUI・タブ名・表示中のページまで対象言語に揃える必要があるため、
普段使いのプロファイルとは別に、その言語のChromeを一時的に立ち上げて撮る。

1. 対象言語でChromeを起動する(既存プロファイルに影響しない)

   ```
   chrome.exe --lang=en-US --user-data-dir=%TEMP%\dehistory-shots-en
   ```

2. `chrome://extensions` でデベロッパーモードを有効にし、`src/` を
   「パッケージ化されていない拡張機能を読み込む」で追加する
   (Chrome 137 以降 `--load-extension` は使用できない)

3. 拡張機能のアイコンをツールバーにピン留めする
   (パズルピースのメニューからピン留め。ポップアップの表示位置がこれで決まる)

4. 以下を撮影する

   - `screen1` — 任意のサイトを開き、ツールバーのアイコンからポップアップを表示した状態
   - `screen2` — オプションページをタブで開いた状態

5. `screenshots/<言語>/` に配置する

### 注意点

- **ウィンドウは「物理ピクセルで」1280x800 にする。**
  ディスプレイのスケーリングが効くため、Chromeから見た論理サイズは physical とは一致しない。
- **表示倍率は2枚で変える。**
  ポップアップはブラウザUIなのでページの拡大では大きくならず、
  表示倍率(`--force-device-scale-factor`)でしか調整できない。
  - `screen1`(ポップアップ) … 1.75。ポップアップが十分な大きさになる
  - `screen2`(オプション) … 1.45。1.75のままだと高さ200pxの許可リスト入力欄が
    画面外に出てしまう。1.45でCSS上のビューポートが約 1267x707 になり全体が収まる
    (2.0まで上げるとオプション画面が横にはみ出して横スクロールバーが写り込む)
- **背景ページはシンプルなものにする。**
  情報量の多いページだと拡張機能のUIが埋もれる。現在は `example.org` を使用。
  `example.com` は許可リストの記入例に使っているため、背景に使うと
  ポップアップが「許可リストから外す」状態になってしまう。
  未登録のドメインにして「許可リストに追加する」を見せる。
- **背景に出すページに Google 検索を使わない。**
  自動操作とみなされるとreCAPTCHA画面になり、そこにグローバルIPアドレスが表示される。
- ポップアップは他のウィンドウにフォーカスが移ると閉じる。
  ウィンドウの位置とサイズは、ポップアップを開く前に確定させておく。

## 注意

UIの文言を変更したら全言語とも撮り直すこと。
文言は `src/_locales/<言語>/messages.json` が正となる。
